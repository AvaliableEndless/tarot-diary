# 卡片内容与精简排版

## 内容来源

2026-11-22 核对 [Labyrinthos 全 78 张牌关键词表](https://labyrinthos.co/blogs/tarot-card-meanings-list)。该表包含全部大、小阿尔卡那的正位/逆位关键词与单张牌链接；本版只采用正位常见象征，中文为编辑概括，不宣称所有塔罗体系释义完全一致。

`apps/web/src/data/symbolism.json` 用明确的牌 ID 记录三个象征、一个简短日常联想和原牌义链接路径；`domain/cards.js` 将它与牌面目录关联。来源的核对日期和正位范围也随数据记录。

常见象征与原创联想分开：例如星星的「希望、信念、复苏」对应来源中的 hope、faith、rejuvenation；「今天，一句回应或一个小进展，也许会带来期待」是原创日常联想。后者使用可能性或条件描述，不作为牌义原文引用。

审判牌保留用户认可的展开文案：

> 旧的经历可以有新的解释。先记录今天的看法，也允许以后的自己继续改变。

这段话位于详情的「今日联想」中，与带链接的「常见象征」区分。

## 首页层级

1. 牌面与牌名。
2. 一行常见象征。
3. 一句今日联想，窄屏最多两行。
4. 「留一句」入口，继续支持长按识别。

移除额外的牌下编号、斜线、英文名、原创副标题、「今日提醒」和保存状态行。详细来源与完整反思移至详情，信息与重播图标和牌名共用一行，各保留 44 px 点击目标和悬停提示。
