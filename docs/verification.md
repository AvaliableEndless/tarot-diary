## 覆盖的主要行为

每日牌刷新保持、再次更新不替换旧牌、语音前先记文字、只点选「没有发生」、编辑退出确认、文字保存后回看、牌库筛选搜索、不支持 ASR 的降级、损坏数据不自动覆盖、配额失败保留草稿、跨午夜切换、原声音持久化与导出。

浏览器录音测试通过 Chromium 测试麦克风验证 MediaRecorder 的开始、暂停、继续、结束、刷新后读取和 JSON 导出。语音适配的单元测试检查最终转写与临时结果的分离、错误及终止事件。

长按测试使用真实 MediaRecorder 与测试麦克风，并通过模拟 SpeechRecognition 回调检查调用次数、结束后的最终文本、音频与文字持久化。权限延迟用例确认松开后返回的所有音轨都已结束，识别没有启动。上述用例验证流程，不代表真实中文识别准确率。

另验证了录音初始化失败时释放麦克风，以及移除录音并清空文字后禁止保存空记录；放弃修改后，原文字与原声音仍能读取。软键盘用例通过模拟 VisualViewport 变化检查保存按钮位置，不等同于真实 iPhone/Android 实机验收。

抽牌动效在 390 px 和 1440 px 视口逐帧检查，实际牌面在解码后翻开并落到最终展示位置。另检查了 320 px 与 768 px 动画中的横向溢出以及调整视口后的中断恢复，结果正常。该验证不代表所有真实移动设备的性能测试。

本次独立 Edge 测试浏览器在系统减少动态效果下截图检查完整翻牌与手机/桌面录音浮层，文件为 `mobile-full-motion.png`、`mobile-hold.png`、`mobile-hold-review.png`、`desktop-hold.png`。完整模式读取到 `draw-card-reveal` 动画与可见正面。此前用户实际 Edge 标签报告减少动态效果，定位旧版跳过动画的原因；本次重试时插件返回 `Debugger unattached`，窗口工具随后因无法确认网址是否允许访问而停止，未完成用户实际窗口的最终验收，也未改动其浏览器权限或录制真实环境声音。

重播洗牌补充验证：3 个新用例在修复前均复现失败，修复后通过。390 px 与 1440 px 下，在柔和偏好和系统减少动态效果同时开启时，重播仍显示完整三张牌；逐帧测量左右牌中心均向外移动超过 12 px，三张图已加载，跳过按钮不与牌面边界相交，牌意在重播结束后恢复，原偏好保持不变。另截图检查 320、768、1440 px 重播，牌面可见且没有横向溢出。`draw-preview.gif` 已从当前网页重新录制，共 19 帧。
