每日一牌

三张看今天，
一张看眼下。

大多数记录工具都要求你「想清楚了再写」。
但人的一天常常是模糊的、说不清的、懒得整理的。

所以我们把门槛降到最低：抽一张牌，给你一个开口。
你只要开口说今天发生了什么，剩下的交给它。

两 种 抽 法

  1. 今日三张 — 每天一次。摊开十张，自己选三张，看今天的整体走向。选定即锁定。
  2. 问一张 — 随时可抽，次数不限。同样摊开十张，选一张，回应眼前这件具体的小事。
  3. 说话 — 三张之后，按住说今天发生了什么，它替你留下一句。
  4. 回响 — 第二天抽三张时，你会看到昨天那句话。

牌 库

完整 78 张塔罗（22 张大阿卡纳 + 56 张小阿卡纳）。
牌面图片放在 cards/ 目录，按 00.jpg · 01.jpg … 77.jpg 命名即可。
没放图时，自动退化为几何符号牌面。

技 术 说 明

形态　单文件 HTML，零依赖，双击即用
语音　浏览器原生 Web Speech API
需 https 或 localhost；本地打开时可用「示例」跑通
音效　Web Audio API 实时合成，无音频文件
提炼　本地规则引擎，可替换为华为云大模型推理接口
数据　仅存本机 localStorage，不上传
