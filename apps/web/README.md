# 拾念 · React 工程版

从仓库根目录运行，要求 Node.js >= 22.12：

```sh
npm ci
npm run dev
```

应用：<http://127.0.0.1:4175/>；四屏设计板：<http://127.0.0.1:4175/design-board.html>。

```sh
npm run check
npx playwright install chromium
npm run test:e2e
```

`check` 包括 ESLint、Node 单元测试、78 张牌面完整性检查和生产构建。浏览器测试覆盖抽牌锁定、复盘、编辑、日期切换、保存失败和录音回听/导出。录音测试使用浏览器测试麦克风，不代表真人语音识别准确率。

已有 Chromium/Edge 时，可通过 `PLAYWRIGHT_EXECUTABLE_PATH` 环境变量指定浏览器可执行文件，跳过浏览器下载。

## 代码边界

- `app/`：应用状态与页面/面板编排。
- `pages/`：今天、历史和牌库。
- `features/`：录音复盘表单、原记录详情、数据设置、牌面详情。
- `components/`：共享对话框、记录项、昨天入口。
- `domain/`：卡牌内容、日期和日记规则，不直接访问浏览器存储。
- `hooks/`：日记状态与本地日期变化。
- `services/`：LocalStorage、IndexedDB、转写适配和导出。
- `data/`、`fixtures/`：78 张牌目录和带来源标记的演示记录。
- `styles/`、`public/cards/`：页面样式与完整 WebP 牌图。

## 已实现

每天一张固定牌；78 张牌的独立观察问题；次日可跳过的复盘；结果点选；真实录音、暂停、回听；浏览器可用时自动转写；文字编辑；日历筛选和历史补写；音频与文字本地保存；带原音频的 JSON 导出；可清除示例记录。

桌面端采用顶部导航和独立录音入口，今日牌面与提示并排，回看页以日历和记录双栏展示。手机端保留底部录音入口，适配安全区和软键盘高度；复盘面板可内部滚动，保存操作保持可见。回看支持按月份、日期、关键字和记录状态筛选；牌库分类支持键盘方向键。

桌面「留一句」、今日记录入口与手机底部「按住说话」共用长按手势：按住 200 ms 直接录音并尝试转写；松开结束并确认，上滑 72 px 后松开取消。短按或键盘激活打开文字编辑器；第一次需要浏览器麦克风授权。授权晚于松开时停止麦克风，需要重新录制。见 [语音交互设计](../../docs/voice-ux.md)。

抽牌默认包含约 2 秒的三张牌摇动洗牌、抽离、翻面和落位，支持跳过；结果先保存，动画可中断。「重播抽牌」单次播放完整动作，保留同一张牌和已有日记，不修改偏好。设置「抽牌动效」可选跟随系统、完整、柔和，已有明确选择会保留；选择跟随系统且系统减少动态效果时采用柔和淡入。动效预览与时序见 [抽牌动效设计](../../docs/draw-motion.md)。

## 开发框架与数据库

- 前端：React 18、JavaScript / JSX、CSS，使用 Vite 6 开发与构建、Lucide 图标。
- 后端：当前没有后端服务，也没有服务端数据库。
- 文字、抽牌结果与复盘状态：浏览器 LocalStorage。
- 原始录音：浏览器 IndexedDB，它是当前设备内的本地数据库。
- 语音：MediaRecorder 录音；浏览器可选 SpeechRecognition 转写。
- 测试：Node 内置测试与 Playwright；npm workspace 管理项目。

网页在电脑、手机都能使用，但不同设备或浏览器的数据不会自动同步。正式实现账号和多端同步时，可用后端与 PostgreSQL 保存用户和记录，音频文件放对象存储；这部分当前未接入。

保存失败会保留编辑内容，不显示已保存。损坏的旧数据不会在初始化时被自动覆盖。多个标签页的更新会同步；写入前重读已有记录，避免常规情况下覆盖别的标签页内容。LocalStorage 不提供事务锁，严格跨设备或并发一致性需要后端支持。

## 尚未接入

华为云 ASR、AI 提炼、云端账号同步、自动通知、硬件和数据分析服务。当前 `speech-recognition.js` 实现浏览器适配，不是华为云接入占位响应；识别失败会明确提示，音频和文字入口仍保留。

78 张牌各有三个常见象征，来自对 Labyrinthos 全牌正位关键词表的中文概括，详情保留每张牌的来源链接，数据位于 `src/data/symbolism.json`。今日联想、展开的反思文案和复盘问题仍为预设原创文案，与来源象征分开呈现；当前没有逆位抽取。未选择对应结果时，文字保存为「留了一句话」，不会自动判定牌面命中。示例记录有独立标记；`?preview=home|drawn|record|history` 使用内存预览，不写入正式文字记录。

抽牌后的首屏只保留牌名、象征和一句今日联想，另有「留一句」入口。牌下编号、英文标题、重复保存状态与展开文字行已移除；牌义详情与重播使用带提示的图标按钮。你喜欢的审判牌反思原文保留在详情中。见 [内容来源与排版](../../docs/card-content.md)。

## 数据与语音

- 文字及抽牌使用 `shinian-tarot-v1` LocalStorage 键；音频使用 `shinian-audio-v1` IndexedDB。
- 根目录旧版与工程版的数据结构不同，当前没有自动迁移或备份导入。
- 清理浏览器数据前请导出。导出 JSON 内的音频是原始录音的 Data URL。
- 麦克风要求 HTTPS 或 localhost；正式部署需要 HTTPS。
- 浏览器语音识别可能调用浏览器提供商的在线服务，不能承诺音频只在本地处理；只有原录音的保存由本项目控制在当前设备。
- 云端语音应通过后端代理接入，密钥不可放入浏览器代码或 Vite 客户端环境变量。

## 构建与预览

`npm run build` 输出 `apps/web/dist`，可部署到静态服务器；`npm run preview` 在 <http://127.0.0.1:4176/> 查看构建结果。使用系统中文字体，不依赖外部字体请求；录音等面板按需加载。牌图使用用户提供的完整素材，公开发布时应保留真实来源与授权信息。
